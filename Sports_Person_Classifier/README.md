# Sports Personality Classification Web Application

This project is a **Machine Learning and Computer Vision application** that classifies images of sports personalities into predefined categories. The system uses image preprocessing, feature extraction, and supervised learning to identify the correct personality.

---

## 🏅 Classified Sports Personalities
- Maria Sharapova  
- Serena Williams  
- Virat Kohli  
- Roger Federer  
- Lionel Messi  
- Cristiano Ronaldo  
- Max Verstappen  

---

## 🚀 Features
- Image-based personality classification
- Dataset collected via **Google Image Scraping**
- Flask-based backend for prediction
- User-friendly web interface
- End-to-end ML pipeline

---

## 🧠 Machine Learning Workflow
- Image scraping and dataset creation
- Image preprocessing using **OpenCV**
- Feature extraction and data normalization
- Model training and evaluation using **Scikit-learn**
- Data visualization using **Matplotlib & Seaborn**

---

## 🛠️ Technologies Used
- **Python**
- **NumPy & OpenCV** – Image processing and data cleaning
- **Matplotlib & Seaborn** – Data visualization
- **Scikit-learn** – Model building
- **Flask** – Backend API
- **HTML, CSS, JavaScript** – Frontend UI
- **Jupyter Notebook, VS Code** – Development tools
