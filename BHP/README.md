# Real Estate Price Prediction Web Application

This project is an end-to-end **Data Science and Machine Learning application** that predicts real estate prices in Bangalore based on user-provided inputs such as area (sq. ft), number of bedrooms, bathrooms, and location. The project covers the complete lifecycle of a machine learning solution — from data preprocessing to cloud deployment.

---

## 🚀 Features
- Predicts house prices using a trained **Linear Regression model**
- Interactive web interface for user input
- Backend API built with **Flask**
- Deployed using **Nginx**
- Real-time price prediction

---

## 🧠 Machine Learning Workflow
- Data loading and cleaning using **NumPy & Pandas**
- Outlier detection and removal
- Feature engineering and dimensionality reduction
- Model training using **Scikit-learn**
- Hyperparameter tuning with **GridSearchCV**
- Model evaluation using **K-Fold Cross Validation**

---
